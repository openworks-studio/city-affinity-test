# 城遇 - 中国城市旅行偏好测试

一套无需后端即可运行的移动端测试网页。用户完成 16 道旅行场景题后，会获得：

- 命定城市与旅行原型
- 偏好匹配分
- 匹配原因与现实提醒
- 城市美食和代表性景观
- 独立的 3 天轻体验路线
- 独立的 7 天深度路线
- 两个备选城市
- 可下载的 1080 x 1440 结果分享图

当前版本包含 40 座城市：

- 热门经典：北京、西安、上海、成都、重庆、长沙、杭州、南京、苏州、武汉、厦门、广州、深圳
- 山水与滨海：青岛、大理、桂林、昆明、贵阳、威海、烟台、腾冲、丽江、张家界、黄山、西双版纳、恩施
- 文化与小众：泉州、洛阳、景德镇、哈尔滨、敦煌、潮州、福州、扬州、绍兴、大同、开封、兰州、汕头、乌鲁木齐

## 本地预览

进入项目目录后运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8000/`。

## GitHub Pages 发布

1. 在 GitHub 创建一个新仓库。
2. 将 `index.html`、`styles.css`、`data.js`、`cities-extra.js`、`cities-more.js`、`app.js` 上传到仓库根目录。
3. 打开仓库的 `Settings -> Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/ (root)`，点击保存。
6. 等待 GitHub 生成 `https://你的用户名.github.io/仓库名/`。

上线前请在不同地区、运营商和手机上实测访问速度。正式商业投放不建议长期依赖 `github.io`，也不要把前端隐藏内容当成付费鉴权。

## 内容修改

- 题目和选项：编辑 `data.js` 中的 `QUESTIONS`。
- 原有城市、美食、景点与路线：编辑 `data.js` 中的 `CITY_DATA`。
- 第一批扩展城市：编辑 `cities-extra.js`。
- 第二批扩展城市：编辑 `cities-more.js`。
- 色彩与布局：编辑 `styles.css` 顶部的 CSS 变量。
- 计分权重：编辑 `app.js` 中的 `calculateResult()`。

运行 `node validate-data.js` 可以检查城市字段完整性，并用固定随机种子模拟 12 万组答案，确认每座城市都能成为第一结果。

路线中的天气、开放时间和预约政策不会写死在页面中。每次节日前投放前，仍需用景区和城市官方渠道更新说明。
